# Security Policy

## Scope

OrchidOS is currently an early-stage research repository. It does not provide a supported operating-system image or production security guarantees.

## Reporting a concern

Please do not publish exploitable vulnerability details, private keys, personal data, or device-specific security-sensitive information in a public issue.

Contact the repository maintainer privately through the contact method listed on the GitHub profile. Include a concise description, affected commit or file, and safe reproduction context where possible.

## Safe research

- Use test environments and non-production data.
- Do not test against devices, accounts, or networks you do not own or have permission to assess.
- Never commit passwords, access tokens, signing keys, or private device identifiers.
- Treat boot-chain and firmware research as high risk; document concepts and use controlled test setups.
