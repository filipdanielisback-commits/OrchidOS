# Driver Research

This directory tracks research into the hardware interfaces required by a useful system on the Moto G60.

## Areas to investigate

- Display controller and panel.
- Touchscreen and other input devices.
- Storage controllers.
- USB and connectivity.
- Wi-Fi and Bluetooth.
- Audio codec and audio routing.
- Sensors, cameras, and peripherals.
- Clocks, regulators, power, and thermal management.

## Current status

No OrchidOS driver support is claimed. A component appearing in an Android kernel source tree does not mean it can be reused by XNU without substantial analysis and compatible licensing.

For each component, record its exact identity, bus/interface, source documentation, firmware dependencies, upstream driver availability, and unresolved questions.
