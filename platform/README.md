# Moto G60 Platform Research

This directory contains device-specific research for the Motorola Moto G60 (`hanoip`).

## Current status

The platform description is incomplete. The device codename and preliminary SoC identification must be cross-checked against authoritative device-specific sources.

## Planned contents

- Hardware identity and regional variants.
- CPU and memory description.
- Interrupt, timer, clock, and power information.
- Peripheral inventory.
- Device-tree and kernel-source references.
- Known unknowns and evidence links.

## Rules

Every hardware claim must include a source and confidence level. Do not copy a device tree from a related phone and assume it describes the Moto G60. Do not store personal identifiers or secrets in this directory.
