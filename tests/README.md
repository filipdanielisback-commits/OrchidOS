# Test Plans and Results

This directory contains test plans, reproducibility records, and future automated checks.

## Suggested organization

- `plans/` — test objectives and acceptance criteria.
- `results/` — dated summaries and links to logs.
- `scripts/` — OrchidOS-authored test helpers, when needed.

## Requirements

Every test must state its environment, source revision, expected result, observed result, and limitations. Do not commit personal data, credentials, device serial numbers, or unredacted diagnostic output.

A successful host build or virtual experiment must not be described as proof of Moto G60 hardware support.
