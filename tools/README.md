# Development Tools

This directory is reserved for small, reproducible tools that support OrchidOS research.

## Guidelines

- Prefer simple scripts with clear inputs and outputs.
- Document dependencies and supported host environments.
- Pin or record tool versions for reproducible results.
- Avoid collecting personal device data.
- Never embed credentials, tokens, or private keys.
- Explain what each tool verifies and what it does not verify.

No device-flashing or boot-chain modification utility is part of the initial project scope.
